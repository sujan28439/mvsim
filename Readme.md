# MVSIM

## このプロジェクトについて
駅にあるマルス券売機の再現を目指しています。
フロントエンドのみの実装なので、通信は行いません。
（いずれはバックエンド側の再現もやりたい）

## 使い方
### ダウンロード
`git clone https://github.com/sujan28439/mvsim`
### 起動
`index.html` をお使いのブラウザで開いてください。起動後の操作は `guide.html` を参照してください。
